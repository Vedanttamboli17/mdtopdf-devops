🏗 System Architecture
1
API Service
Go + Fiber validates file, uploads to S3, creates DynamoDB job, sends SQS message
2
Amazon S3
Stores raw Markdown (uploads/) and generated PDFs (pdfs/) with private access
3
DynamoDB
Tracks job metadata: status, input_url, output_url, retry_count
4
Amazon SQS
Decouples API from Worker. Long-polling, DLQ after 3 retries, 20s visibility
5
Worker
Polls SQS, downloads MD, converts via wkhtmltopdf, uploads PDF, updates DynamoDB
6
Presigned URL
S3 presigned URL gives temporary 10-min access. PDF never publicly exposed
Built with Go · Fiber · Docker · Terraform · Ansible · Jenkins · AWS Free Tier
